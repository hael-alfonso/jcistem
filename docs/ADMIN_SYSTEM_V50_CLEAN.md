# JCI Carmona Admin System v50

The Admin system is organized around one source module per area: Dashboard, Projects, Tasks & Milestones, LOI, Calendar, Project Reports, Financial Monitoring, Members & Accounts, Member Registration, My Member Dues, Notifications, My Account, and Audit Log.

Dashboard summarizes only. Detailed records remain in their source modules. Financial Monitoring is read-only for Admin; Treasurer retains authoritative financial recording and maintenance.
