# JCI Carmona Admin v43 Visual Theme

The interface uses the current JCI brand palette documented by JCI:
- JCI Blue: #0097D7
- JCI Black: #130F2D
- JCI White: #FFFFFF
- JCI Navy: #1F4789
- JCI Teal: #57BCBC
- JCI Yellow: #EFC40F

Design treatment:
- Light, white-first surfaces with very pale blue/teal page background.
- Blue for primary actions, active navigation, progress and main data emphasis.
- Navy for headings and structural emphasis.
- Teal for supportive / positive data and secondary visualization accents.
- Yellow only for review/attention emphasis.
- Charts are intentionally limited to portfolio status, budget utilization, and progress monitoring.
