# Supplied reference forms

These original DOCX files were supplied by the user on 27 October 2026 and copied unchanged into `resources/forms`. The active-account-only Templates & Forms page links to them through the allowlisted catalog in `config/reference_forms.php`. They do not depend on a Downloads directory or an invented uploader/account record.

| Form | Workflow reference |
|---|---|
| External Partnership Letter | External partner contact, project purpose/impact, requested support, recognition, attachments, and signatory/contact details. Keep separate from internal project initiation. |
| Internal Project Proposal Letter | Project concept addressed to the President and BOD: SDG alignment, objective, schedule, location, beneficiaries, proposed chair, estimated budget/funding, and committee needs. |
| Project Proposal Form | Detailed rationale/objectives, beneficiaries, committee responsibilities, phased plan, estimated income/expenses, funding, expected benefits, and signatures. |
| Liquidation Report | Itemized expenses with receipt date/reference and quantity, cash received versus actual expenses, cash return/reimbursement, supporting receipts, and signatures. |

The documents are reference/download assets, not instructions to change system authorization. Proposed chair names and printed President/VP/Treasurer signature blocks do not grant roles or bypass the existing Admin/Treasurer reviews, recorded BOD decision, PPF lock, or independent report approvals. System fields have not been automatically replaced by the paper forms. PDF conversion and automatic filling of these Word files are not included in this change.

Original formatting is preserved byte for byte. Content was checked using DOCX XML extraction; the documents were not redesigned or visually rendered. There is no completion/PCR template among these four files; additional templates can still be published through the existing Admin upload form.
