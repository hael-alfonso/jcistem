# JCI System v48 — Charts and Folder

## Folder name
The application root folder is `jci system`.

## Chart approach
The chart design favors quick reading:
- Horizontal category bars for status/count distributions.
- Horizontal progress bars for project completion.
- Split budget bars for Used Funds vs Remaining Funds.
- Counts and percentages are printed next to the bars.
- JCI Blue and Teal identify the primary financial segments; Navy is used for labels/structure.
- Yellow remains an attention accent rather than a primary chart color.

This avoids requiring users to estimate angles or decode a legend-heavy donut chart.
