# v47 JCI Visual Cleanup

The uploaded JCI logo was used as the visual reference for the interface.
Palette: #140F2D navy, #0097D7 blue, #57BBBC teal, and #EFC40F yellow for limited attention states.

Icons are larger, semantic, SVG-based icons:
- 20px icons inside 34px sidebar/stat touch targets.
- Dedicated icons for Dashboard, Projects, Create Project, Review, Tasks, LOI, Members, Registration, Dues, Audit, and the brand mark.

Charts are module-specific:
- Dashboard: project status, project progress, budget health.
- Tasks: task status.
- Members: permanent roles.
- Reports: report status.
